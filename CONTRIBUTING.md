# Contributing to Portfolio Website

Thank you for your interest in contributing! This document provides guidelines for contributing to this project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/your-username/portfolio.git`
3. Install dependencies: `pnpm install`
4. Create a new branch: `git checkout -b feature/your-feature-name`

## Development Workflow

1. Make your changes
2. Test your changes locally: `pnpm dev`
3. Build to ensure no errors: `pnpm build`
4. Commit your changes with a descriptive message
5. Push to your fork
6. Open a pull request

## Code Style

- Use TypeScript for all new files
- Follow the existing code style
- Use meaningful variable and function names
- Add comments for complex logic
- Use Tailwind CSS for styling
- Follow React best practices

## Component Guidelines

- Create new components in `src/app/components/`
- Use functional components with hooks
- Implement proper TypeScript types
- Use Framer Motion for animations
- Ensure components are responsive
- Add proper accessibility attributes

## Testing

- Test on multiple browsers (Chrome, Firefox, Safari, Edge)
- Test on mobile devices
- Verify animations work smoothly
- Check for console errors
- Validate forms work correctly

## Security

- Never commit sensitive data (API keys, passwords)
- Sanitize all user inputs
- Follow security best practices in SECURITY.md
- Report security issues privately

## Pull Request Process

1. Update README.md if needed
2. Ensure all tests pass
3. Update documentation if needed
4. Request review from maintainers
5. Address review feedback
6. Wait for approval and merge

## Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Help others learn and grow
- Follow project guidelines
